# v1.1.0 · 27 ноября 2026

- Добавлены остатки товаров, сохранение корзины, оформление и отмена заказов, история покупателя и входящие позиции продавца.
- Добавлена повторяемая миграция 013. Сервер фиксирует цену позиции при покупке, блокирует строки товара в порядке id и возвращает остаток при отмене.
- Существующие оптовые заявки и старые маршруты сохранены.

# Changelog

## [Unreleased] — лабораторная 12, 2026-11-13

### Added
- Тесты React с MSW 2: моки сетевых маршрутов, изоляция состояния, ошибки 400/401/429.
- Страница `/products/:id`, ссылки из карточек, загрузка и ошибки 404/500.
- Удаление товара администратором через интерфейс с подтверждением.
- Два smoke-сценария чтения и локальные E2E добавления/удаления товара, проверки цены.
- Команда `test:run` и компактная упаковка исходников без node_modules и Chromium.

### Changed
- Любой внешний BASE_URL/E2E_BASE_URL/PRODUCTION_URL запускает только smoke.
- `e2e:prod` и ежедневный CI больше не создают пользователей и заявки на продакшене.
- Данные локального E2E-администратора передаются через окружение; пароль генерируется.

## [Unreleased] — кандидат v1.0.0, 2026-11-06

Релиз подготовлен локально. Тег и GitHub Release ещё не опубликованы.

### Added
- Zod-схемы регистрации, входа, товаров, частичного обновления и заявок.
- Ответы 400 с ошибками полей, безопасная проверка id для PostgreSQL SERIAL.
- PATCH товара для администратора, с сохранением неизменённых полей.
- Общий лимит 10 запросов на вход и регистрацию за 15 минут с одного IP.
- Показ ошибок полей и 429 в формах React, тесты API и форм.
- Изолированный запуск серверных тестов через PGlite, `npm run test:server` в корне.
- Проверка production-зависимостей в CI и конфигурация еженедельного Dependabot.

### Changed
- JSON-тело ограничено 100 КБ; пароль — 72 байтами UTF-8.
- Цена должна быть целым числом от 1 до 10 000 000; категория обязательна.
- Ошибки синтаксиса JSON не отражают содержимое запроса в ответе.
- Nodemon перенесён в devDependencies, обновлены доступные совместимые зависимости.

Сохранены каталог, заявки, JWT, проверка ролей, Helmet, строгий CORS,
существующий PUT и тесты ЛР8–ЛР10. Первой версией 1.0.0 фиксируется этот контракт.
