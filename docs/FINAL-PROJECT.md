# Итоговый проект · отзывы покупателей о товарах

Предложение для согласования с преподавателем и напарником. Покупателю проще выбрать товар, если он видит оценки тех, кто действительно покупал его.

- [ ] Только покупатель с исполненным заказом этого товара может оставить отзыв. Отмена не даёт права на отзыв.
- [ ] Один покупатель может поставить товару одну оценку от 1 до 5 и написать комментарий до 1000 знаков.
- [ ] Владелец отзыва может изменить или удалить его. Чужой отзыв изменить нельзя.
- [ ] Страница товара показывает среднюю оценку, число оценок и список отзывов с состояниями загрузки, ошибки и пустого списка.
- [ ] Три серверных теста проверяют права, уникальность отзыва и расчёт рейтинга. Три теста React с MSW и один E2E проверяют интерфейс.
- [ ] После ревью и зелёного CI версия v1.2.0 доступна на учебном сайте.

Миграция 014 создаст reviews(id, product_id, buyer_id, rating, comment, created_at) с внешними ключами, CHECK по оценке и UNIQUE(product_id, buyer_id). GET /api/products/:id/reviews вернёт отзывы и рейтинг. POST по тому же адресу создаст отзыв. PATCH и DELETE /api/reviews/:id разрешены владельцу. Условие исполненного заказа проверяется по purchase_orders.status = 'shipped' и order_items.

Первый участник отвечает за миграцию, API и серверные тесты, второй за интерфейс, MSW и E2E. Каждый ревьюит PR напарника. Назначение конкретных GitHub-аккаунтов и согласование темы с преподавателем остаются за участниками.
