Старый тест лимита ЛР9 обновлён с 5 до 10 запросов по новому требованию; остальные
проверки не удалялись. Тесты подтверждают 400 для неверного email/цены/id/пустого PATCH,
413 для тела более 100 КБ, нормализацию ввода, ограничения пароля в байтах, невозможность
назначения admin при регистрации, успешное частичное обновление, заголовки Helmet/CORS,
21 попытку входа с переходом 401 → 429 и независимость бюджета разных IP.

Серверные проверки используют настоящие SQL-запросы через pg к изолированной PGlite,
не моки pool. База уничтожена по завершении. GitHub CI использует PostgreSQL 17;
сам облачный CI из этой папки не запускался. E2E использует отдельную временную БД
и настоящий браузер. Рабочая DATABASE_URL не использована.

Снимки npm audit до/после: [security-audit](security-audit/).

Не выполнены: Git-история секретов (нет .git), PR/ревью, публичный production E2E,
публикация тега/релиза, замер отката Vercel. План завершения — [RELEASE.md](../RELEASE.md).
