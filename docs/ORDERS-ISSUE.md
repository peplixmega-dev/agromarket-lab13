# Заказы

Покупатель может купить несколько товаров, а фермер видит позиции, которые нужно доставить.

- [ ] У товара есть остаток. Добавление недоступно, когда он равен нулю.
- [ ] Корзина сохраняет позиции после перезагрузки.
- [ ] Заказ, его позиции и списание остатков записываются одной транзакцией.
- [ ] Сумму определяют цены из базы, цена позиции сохраняется на момент заказа.
- [ ] Нехватка любой позиции возвращает 409 с доступным количеством, без частичного списания.
- [ ] При одновременной покупке последней единицы проходит один заказ.
- [ ] Покупатель видит свои заказы и может отменить новый; продавец видит позиции своих товаров.
