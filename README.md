# АгроМаркет · ЛР13 · v1.1.0

Покупатель добавляет товары в корзину, указывает адрес, оформляет заказ и может отменить его, пока заказ новый. Продавец задаёт остатки и видит заказы на свои товары. Сайт также принимает оптовые заявки из предыдущих лабораторных.

На Mac откройте **start-demo.command** и перейдите на http://localhost:3000. Локальная демобаза создаётся заново при каждом запуске. Демо-продавец входит как `admin@agromarket.kz` с паролем `DemoAdmin12345!`. Покупателя можно зарегистрировать через сайт.

**Проверки.** Откройте **start-tests.command**. Полный архив включает установленные зависимости и Chromium для macOS arm64. На другой платформе выполните `npm run setup` из корня и `npx playwright install chromium` из client. Для запуска нужен Node из диапазона engines в package.json.

## Рабочая локальная заглушка

Откройте `start-demo.command` или выполните `npm run demo` в корне. Сайт и API: http://localhost:3000. Администратор: `admin@agromarket.kz`, пароль `DemoAdmin12345!`. Каталог, регистрация, заявки, админка и `/api/categories` работают через тот же Express API. Вместо Neon используется отдельная база PGlite в памяти; после остановки данные сбрасываются. Реальная DATABASE_URL в деморежиме не используется.

Зависимости на этом компьютере уже установлены. Для свежего клона: `npm run setup`. Обычный `npm start` из `server` запускает сервер с настоящим PostgreSQL; демобаза в продакшене не используется.

Проверки: `npm test` из `server`; `npm run lint` и `npm run build` из `client`. Серверные интеграционные тесты требуют отдельную локальную базу `agromarket_test` и переменные DATABASE_URL, JWT_SECRET, CORS_ORIGIN, ADMIN_EMAIL, ADMIN_PASSWORD. В тестовом CORS_ORIGIN нужны `http://localhost:5173,https://frontend.example`.

Проверено локально: 22 серверных теста на PostgreSQL, lint и сборка React, 5 smoke-проверок, регистрация → заявка → просмотр админом.
